# 🎓 Hebron University RAG Guide

An AI-powered Retrieval-Augmented Generation (RAG) assistant designed to answer student queries about Hebron University's registration, grading, and graduation rules.

> ⚠️ **Disclaimer:** This application is a proof-of-concept (PoC) built solely for educational purposes to demonstrate Retrieval-Augmented Generation (RAG) concepts using ChromaDB. It is not an official Hebron University service, and outputs should be independently verified.

---

## 🚀 Features
- **Smart Retrieval:** Uses ChromaDB and vector search to find accurate university guidelines.
- **Interactive Interface:** Built with Gradio for a seamless user experience.
- **Fast Answers:** Instant responses grounded directly in official documents.

---

## 🛠️ Tech Stack
- **Python 3.10+**
- **Gradio**
- **ChromaDB / LangChain**
